### 🧑‍💻 About me

- 🎮 I run **[Wazang Games](https://wazanggames.com)**, my indie studio, and own the code end to end: architecture, gameplay, UI, multiplayer, builds and the Steam release.
- 🧩 Before that I was a Unity Developer at **Narcade**, building meta and LiveOps features (Lava Quest, Battle Pass, Competitions, Daily Rewards, User Profile) for Match-3 / Match-3D mobile puzzle games.
- 🏗️ I care about architecture: dependency injection (Zenject, VContainer), ScriptableObject-driven content, SOLID, unit tests, and profiling until the frame time is flat.
- 🌐 I've built online and shared-screen multiplayer for up to 8 players with FishNet and Steamworks.
- ⚡ Electrical & Electronics Engineer by degree. I started out writing embedded C for STM32 before moving into games.

### 🛠️ Open source

- **[Steam Build Pipeline](https://github.com/wazzapsenk/steam-build-pipeline)**: a Unity Editor tool that builds a Windows64 player, generates the Steamworks VDF scripts and uploads through steamcmd without leaving the Editor. Demo, Playtest and Prod are separate environments with their own AppIds, depots and branch whitelists, so a build can't ship to the wrong app. MIT licensed, installable as a UPM git package.
